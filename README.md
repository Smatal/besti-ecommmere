# Bestie Cares — E-Commerce Storefront

Bestie Cares is a modern, high-performance direct-to-consumer (D2C) e-commerce storefront for science-backed skin and hair care products. Formulated with dermatologically tested active ingredients, the platform offers an intuitive, responsive shopping experience with routine builders, interactive product detail views, dynamic cart management, and seamless order checkout flows.

## 🌟 Key Features

- **Dynamic Product Catalog**: Sunscreens, Vitamin C Serums, Cleansers, Face Washes, Hair & Scalp Care, and Curated Routine Bundles.
- **Interactive Product Detail Pages (PDP)**: High-resolution media, single/duo pack selection, active ingredient breakdowns, INCI transparency, comparison tables, and customer reviews.
- **Routine Finder & Quiz**: Guided recommendations based on skin concern (Acne, Pigmentation, Aging, Hair Fall, Sun Protection).
- **Interactive Cart & Drawer**: Quantity management, free shipping tier calculator, coupon codes, and bundle upsells.
- **Checkout Modal**: Multi-step checkout with address validation, UPI / Card / COD payment options, and instant order confirmation modal with download/print invoice support.
- **Fast & Responsive**: Built with clean modern HTML5, CSS3 variables, and vanilla JavaScript powered by Vite.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) (bundled with Node.js)

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Smatal/besti-ecommmere.git
cd besti-ecommmere
npm install
```

### Development Server

Start the local Vite development server:

```bash
npm run dev
```

Open your browser at `http://localhost:3000` (or the URL shown in terminal).

### Production Build

Build minified and optimized assets for production:

```bash
npm run build
```

The output will be generated in the `dist/` directory.

### Preview Production Build

Preview the production build locally:

```bash
npm run preview
```
